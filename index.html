    How it works

    You get taught the way real drawing instructors teach — big shapes first, detail later, shading last:

    1. Set up the grid. We lay a lettered/numbered grid over your photo — the classic technique for copying proportions. Draw the same grid lightly on your paper.
    2. Block in the big shapes. Start loose with just the main outlines, so everything is placed correctly before any detail.
    3. Mark the proportions. For portraits we add Loomis-style guide lines (brow, eyes, nose, mouth) — because the #1 beginner mistake is placing the eyes too high (they sit halfway down the head!).
    4. Refine cell by cell. Clean sketch lines are revealed one grid cell at a time — the face first. Click any step to replay it.
    5. Add shading. Squint to find the darks, then build them up with hatching.
    6. Erase the grid — and you've drawn the photo!

    💡 The sketch lines come from XDoG, a technique that produces clean, hand-drawn-looking lines instead of tracing every bit of texture. Curious about the method? See the resources folder in the project.
